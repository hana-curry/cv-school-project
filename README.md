> This project is a simple CV made with HTML, CSS, and jQuery as a school project for my 2nd year in my Computer Science bachelor's.  

## 📦 Installation

<br>

1. Clone the repo
```bash
git clone https://github.com/hana-curry/cv-school-project.git
```

<br>

2. Launch the `index.html` file which is inside of the repo you just cloned.

<br>
